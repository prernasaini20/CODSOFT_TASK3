# ATM Interface

## About the Project

This project is developed as part of the CodSoft Java Development Internship. It is a console-based ATM simulation that allows users to check their balance, deposit money, and withdraw money through a menu-driven interface.

## Features

* Check the current balance.
* Deposit money into the account.
* Withdraw money from the account.
* Check for insufficient balance.
* Validate deposit and withdrawal amounts.
* Display the updated balance after transactions.

## Technologies Used

* Java
* Scanner class
* Switch statement
* While loop
* Conditional statements

## How to Run

1. Install JDK on your system.

2. Download or clone this repository.

3. Open the project folder in the terminal.

4. Compile the Java program:

   javac ATMInterface.java

5. Run the program:

   java ATMInterface

## Initial Balance

The account starts with an initial balance of Rs. 5000.

## Example

If the user deposits Rs. 2000 into an account with an initial balance of Rs. 5000, the updated balance becomes Rs. 7000.

If the user attempts to withdraw more money than the available balance, the program displays an insufficient balance message.

## Learning Outcomes

This project helped me practice Java loops, switch statements, conditional statements, user input handling, and basic transaction operations.
